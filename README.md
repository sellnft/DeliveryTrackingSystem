# Система отслеживания доставок

## Назначение
Система предназначена для автоматизации процессов отслеживания статуса заказов и обеспечения прозрачности логистических цепочек, как для клиентов, так и для исполинтелей доставки.

## Целевая аудитория
 - **Клиенты** - лица, ожидающие получение заказов;
 - **Курьеры/водители** - сотрудники службы доставки;
 - **Менеджеры логистики** - координаторы процеесов доставки;

## Описание предметной области
Предметная область охватывает процессы логистики и управления доставкой товаров. Включает в себя этапы: создание заказа, назначение курьера, фиксация промежуточных статусов, уведомление клиентов об изменениях и завершении доставки с подтверждением получения.

## Основные сущности
- **Заказ** — содержит информацию о товаре, отправителе, получателе, статусе доставки, временных метках;
- **Маршурт** - включает в себя начальную и конечную точки доставки;
- **Курьер** — данные о сотруднике, транспортном средстве, статусе занятости и местоположении;
- **Пользователь** — профиль клиента, контактные данные, история заказов;

## Основные функции
- Регистрация и авторизация пользователей
- Создание и управление заказами
- Назначение курьера на заказ
- Обновление статусов доставки (создан, принят, в пути, доставлен, возврат)
- Автоматическое уведомление клиентов об изменении статуса заказа
- Аналитическая панель для менеджеров (статистика, загрузка курьеров, время доставки)
- Поиск и фильтрация заказов по различным параметрам

## План развития проекта

1. **Фаза 1 (Базовый функционал)**  
   - Регистрация и авторизация пользователей (клиенты, курьеры, администраторы)  
   - Создание, редактирование и отмена заказов  
   - Назначение курьера на заказ вручную  
   - Ручное обновление статусов заказа (создан → принят → в пути → доставлен / возврат)  
   - Просмотр списка всех заказов с фильтрацией по статусу и дате  

2. **Фаза 2 (Улучшение интерфейса и удобства)**  
   - Личный кабинет клиента с историей заказов  
   - Личный кабинет курьера со списком назначенных заказов  
   - Админ-панель для управления пользователями и заказами  
   - Поиск заказов по номеру, адресу или ФИО получателя    

3. **Фаза 3 (Дополнительные возможности)**  
   - Возможность клиента отменить заказ до момента отправки  
   - Добавление комментариев к заказу (пожелания по доставке)  
   - Статистика для администратора (количество заказов за период, среднее время доставки)  
   - Экспорт списка заказов в Excel/CSV для отчётности    

4. **Фаза 4 (Оптимизация и надёжность)**  
   - Логирование действий пользователей для аудита  
   - Покрытие кода тестами (модульные и интеграционные тесты)  
   - Настройка прав доступа (роли: клиент, курьер, администратор, супер-админ)  

5. **Фаза 5 (Масштабирование и дополнительные сервисы)**  
   - Поддержка групповых заказов (несколько товаров в одной доставке)  
   - Возможность назначения нескольких курьеров на крупные заказы   
   - Внедрение рейтинга и отзывов о работе курьеров
